# Структура

- 'cmd': Запуск приложения
- 'internal': Содержит все основные файлы для бэкенда
    - 'config': Структуры, парсинг ENV
    - 'domain': БД объекты
    - 'delivery': Слой http
        - 'handlers': Принимает запрос-ответы от http
        - 'middleware': Auth проверки, 
    - 'repository': Запросы в базу данных
    - 'service': Бизнес-логика системы
